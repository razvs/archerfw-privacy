Delete game data

To delete your ArcherFW game profile, open Profile → Account → Delete all data in the app. Approve the separate confirmation dialog. Deleting a cloud profile requires internet.

The confirmed process targets the game’s Unity Authentication identity, Cloud Save profile in the active environment, Player ID reservation and related local saves on this device. If the process is interrupted or pending, follow the game’s status message; clicking once does not prove completion.

If you cannot access the app, email the address below with the subject “ArcherFW data deletion”. Include your Player ID and player name if known. Ownership must be verified; the public Player ID alone is not authentication. Losing anonymous profile access can limit secure identification.

Uninstalling or turning off cloud saves does not automatically delete server data. Separate local copies on other devices must be deleted there. Any retention of support messages, provider security logs or backups is governed by the final privacy notice’s retention rules; this page does not promise immediate erasure of all provider logs.

Do not send passwords, sign-in codes, authentication tokens or payment-card details. The Player ID is not a recovery code.
