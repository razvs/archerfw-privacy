03Guest accounts and cloud saves

Cloud saving is optional. Accept in the first in-game choice starts Unity guest authentication and cloud saves. Declining or closing keeps the profile local and the game playable. You can change the choice under Profile → Privacy.

Cloud mode associates the player name, progress, equipment and in-game balances with an automatically generated Unity identifier. The provider also processes technical connection data. The separate five-character Player ID appears only after server allocation; it is not a credential or recovery code.

This version has no email registration or persistent-account linking interface. Reinstalling or losing guest credentials may lose access. Future account features will be explained when introduced.

Moving a local profile to the cloud requires server validation of rewards, spending and ownership. A rejected transfer preserves the local profile; a local upload does not validate purchases or financial entitlements. Disabling cloud saves stops further synchronization but does not itself delete data previously stored on the server.

08Deleting ArcherFW game data

Uninstalling the app or disabling cloud saves does not itself delete a previous cloud profile. The current deletion function concerns the anonymous ArcherFW game profile; there is no separate email or Unity Player Accounts account in the game.

In the updated client, use Profile → Account → Delete all data to request erasure of your game profile. After separate confirmation, the process removes the game’s Unity Authentication identity, profile data in the active cloud environment, the Player ID reservation and related local saves on this device. Cloud erasure requires an internet connection. If interrupted, the game shows a pending state and does not restore the previous save.

If you cannot access the in-game feature, request deletion of ArcherFW game data at archerforgottenworlds@gmail.com. The controller verifies profile ownership; the public Player ID alone does not authorise deletion. Do not send passwords or sign-in codes. Retention rules for support correspondence and provider logs must be specified separately in the final notice.

09Audience, advertising and cookies

ArcherFW is intended for a general audience and is not specifically directed to children. Concerns involving a child’s data can be raised with the privacy contact above.

This notice page has no own analytics, cookie-setting code, embedded trackers, forms or external fonts. External linked pages have their own policies.

Advertising, analytics and purchasing SDKs in the shipped game require a separate review. A tracker-free notice page does not mean that the game’s cloud services process no data.
